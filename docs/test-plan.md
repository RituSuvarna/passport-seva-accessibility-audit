# Accessibility Test Plan

## Scope
Audit the public Passport Seva website using Lighthouse and keyboard-only navigation.

## Tests
1. Run Lighthouse Accessibility audit.
2. Verify keyboard focus order using Tab.
3. Check that interactive controls have accessible names.
4. Check that form controls have associated labels.
5. Check images for appropriate alternative text.

## Safety Boundary
No login, personal information, appointment booking, payment, CAPTCHA submission, or security-control bypassing will be performed.
