# Passport Seva Accessibility Audit

An evidence-based accessibility audit of the official Passport Seva website.

## Scope

- Lighthouse accessibility audit
- Keyboard-only navigation review
- Public pages only
- No login or personal information used
- No appointment booking, payment, or CAPTCHA submission

## Selected Journey

Check Appointment Availability → Bengaluru → PSK Mangaluru

## Project Structure

- `client/` — frontend
- `server/` — backend API
- `docs/` — documentation
- `evidence/` — audit screenshots
- `tests/` — test files
- `src/` — supporting project files
